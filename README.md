# Herculist

**Created by Aryan**

Herculist is a gamified productivity app that merges a task‑focused timer with a to‑do list. Declare your work type (study, workout, project, or chores), track tasks seamlessly, earn badges and streaks, export progress to Excel, and start instantly without login. Every tick is a victory.

## ✨ Features
- Task‑Focused Timer: Start the clock while declaring your work type.
- Integrated To‑Do List: Manage tasks directly inside the timer.
- Gamified Experience: Unlock badges, streaks, and milestones.
- Excel Export: Download progress and history instantly.
- No Login Required: Jump straight into productivity.

## 🚀 Getting Started
1. Clone the repo:  
   `git clone https://github.com/<your-username>/herculist.git`
2. Open `index.html` in your browser.
3. Start conquering tasks!
